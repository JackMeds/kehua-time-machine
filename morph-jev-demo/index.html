NOT MAGIC. A DIFFERENT CONTRACT.

它到底变了什么？

自然语言 + 状态↓Jev：选择 / 评分↓白名单组件 + 安全规则↓布局、显隐、主按钮、下一步动作

这不是“取消编程”，而是减少写死的分支。

组件、数据结构、动作处理器仍然是代码。模型决定何时展示哪个组件、主次关系和动作选择；它不生成 HTML、JavaScript 或新功能。

你能在这里试什么

用不同表述要求专注、研究、诊断、记录。勾掉一个任务、固定一个模块或锁住布局，再观察决策。沙盘里修改任务目标，对照工坊行为。

哪些是真实的，哪些是样例

便笺、任务勾选、计时器和 Markdown 导出在本地可用。资料卡、任务和诊断是演示内容，没有读取 GitHub、Codex 或 Minecraft。只有选中 Jev API 并成功返回时，决策才来自模型。

API 连不上怎么办

先检查 Key、接口地址和原生协议。浏览器显示 Failed to fetch 可能是跨域、网络、证书或混合内容限制；不能单凭它判断是哪一种。完整下载包内运行 node server.mjs，通过本机地址打开，再选择“本机桥接”可避开上游浏览器 CORS 限制，仍需本机能访问 API。

固定模块会保留显示；锁定布局会保留布局；核心决策置信度不足时需手动应用。模型不会自动执行工作台按钮。
